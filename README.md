# EMBER — лендинг ресторана

**Кейс-стади:** [case-study.html](case-study.html) · **Демо:** https://philippkasharov-bit.github.io/ember-restaurant/

Концепт лендинга ресторана на открытом огне: тёмная премиальная стилистика, меню, события, форма бронирования.

## Стек
- HTML, CSS, JavaScript без фреймворков
- Адаптивная вёрстка, мобильное меню
- Анимация появления блоков (IntersectionObserver), учёт prefers-reduced-motion

## Запуск
Открыть `index.html` в браузере. Для публикации — перетащить папку на https://app.netlify.com/drop
